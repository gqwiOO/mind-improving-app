# Куточок

Особистий застосунок для Windows і macOS: записи, книги, короткі замітки,
проєкти й посилання. Усе зберігається локально, у звичайних текстових файлах.

Без хмари, без акаунтів, без інтернету.

## Розділи

| | Що це |
| --- | --- |
| **Записи** | Довгі тексти: думки, чернетки, щоденник |
| **TIL** | Today I learned — дрібниці, які шкода забути |
| **Книги** | Прочитане з оцінками, статистикою й графіком за роками |
| **Проєкти** | Те, що робиш або зробив |
| **Посилання** | Збережене на потім, згруповане по темах |

У кожному розділі є пошук; у записах і замітках — ще й фільтр за тегами.

## Запуск

```bash
dotnet run --project src/Kutochok/Kutochok.csproj
```

Потрібен [.NET 9 SDK](https://dotnet.microsoft.com/download).

## Де лежать дані

```
Документи/Kutochok/
  notes/*.md        ← записи
  til/*.md          ← замітки
  books.yaml        ← книги
  projects.yaml     ← проєкти
  links.yaml        ← посилання
```

Це звичайні markdown- і yaml-файли. Їх можна відкрити будь-яким редактором,
покласти в Dropbox чи git, скопіювати на іншу машину — застосунок не є
єдиним способом дістатися власних текстів. Кнопка «Відкрити теку» в нижньому
лівому куті веде саме туди.

Записи мають службову «шапку», далі — звичайний текст:

```markdown
---
title: Заголовок
date: 2026-08-20
tags:
  - щось
---

Текст запису.
```

## Редактор

Панель інструментів над полем: **Ж**, *І*, підзаголовки, посилання, цитата,
списки, код, роздільник. Під капотом — звичайний markdown, тому текст
лишається читабельним і без застосунку.

Кнопка «Передперегляд» показує, як це виглядатиме відформатованим.

## Імена файлів

Заголовок сам перетворюється на ім'я файлу за офіційною транслітерацією
(постанова КМУ №55): «Привіт, світе» → `pryvit-svite`. Ім'я видно в полі
внизу форми, і його можна виправити вручну.

## Збірка застосунку

**Windows:**

```bash
dotnet publish src/Kutochok/Kutochok.csproj -c Release -r win-x64 \
  --self-contained -p:PublishSingleFile=true
```

**macOS** (збирати треба на Mac):

```bash
# Apple Silicon
dotnet publish src/Kutochok/Kutochok.csproj -c Release -r osx-arm64 \
  --self-contained -p:PublishSingleFile=true

# Intel
dotnet publish src/Kutochok/Kutochok.csproj -c Release -r osx-x64 \
  --self-contained -p:PublishSingleFile=true
```

`--self-contained` кладе .NET усередину, тому на цільовій машині нічого
встановлювати не треба.

Застосунок не підписаний, тому macOS при першому запуску скаже, що
розробник невідомий. Обхід: правою кнопкою на застосунку → «Відкрити».

## Як додати нове поле

Уся форма будується з опису в `src/Kutochok/Models/Schema.cs`. Додав туди
`FieldDef` — поле саме з'явилося у формі, збереглося у файл і почало
враховуватися в пошуку. Окремий код для кожного розділу писати не треба.

Так само додається цілий новий розділ — одним записом `CollectionDef`.

## Структура коду

```
src/Kutochok/
  Models/
    Schema.cs         ← опис розділів і полів (головний файл)
    Entry.cs          ← один запис
  Services/
    ContentStore.cs   ← читання й запис файлів
    Frontmatter.cs    ← markdown + службова шапка
    ContentPaths.cs   ← де лежать дані
    Slug.cs           ← транслітерація імен файлів
    MarkdownRenderer.cs ← markdown → контроли Avalonia
  ViewModels/
  Views/
```

Технології: .NET 9, Avalonia 12, YamlDotNet, Markdig.
